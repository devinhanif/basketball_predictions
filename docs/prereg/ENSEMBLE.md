## Why
Two loose ends in the ledger have never been closed against what production is today.
1. **T387.** XGBoost pts (A1) beat the production lower-tail mixture by -0.0148 [-0.0214, -0.0085] on rows where the player played >= 5 minutes, and lost by +0.1620 [+0.1448, +0.1800] on the 8.4% of rows under 5 minutes (T382-T388; question CLOSED because A1 - A0 overall was -0.0036 [-0.0094, +0.0019] in 2023 and -0.0000 in 2024). Realised minutes are not knowable at tip. The open question is how much of the gap a PRE-TIP minutes probability recovers.
2. **T065-T072.** The sequence transformer alone lost on pts/reb/ast and tied fg3m, but the 50/50 and learned blends on pts were -0.0058 [-0.0100, -0.0016] and -0.0058 [-0.0091, -0.0025] (2024 only, 19-level grid, against production BEFORE the lower-tail mixture, BEFORE integer support, on the pre-clean-up data). Marked KEPT, never followed up. Production has since gained exactly the mixture that fixes the short-minutes rows the sequence model may have been fixing.
Devin added: more history. The 2019-20 and 2020-21 box scores exist (`data/history/nba_history.duckdb`) with a different injury-report regime, so for E3 every report token is treated as missing, as HISTORY_WINDOW_3 does for the props GBM.

**E1 is post-hoc by origin.** The idea of routing between A1 and A0 by minutes came from the minutes >= 5 / < 5 slices of T387 on 2024, after the XGB_PTS_VS_LT rule had CLOSED that question with "no variants" (its P1 failed in 2023). Proceeding with E1 as a NEW router hypothesis under a new id is Devin's call (reported to the main session as confirmed); a pre-tip gate is information the closed rule did not test and the oracle bound is computable. Consequence: E1's prior is low, 2023 is not independent, and a pass is a shadow arm only.

## Hypotheses (each its own arm; counter-hypothesis first)
Counter: production already contains the recency baseline, the lower-tail mixture and the T-60 report; architecture-only ideas have lost or tied every time (RAPM, set transformer, pbp GPT, rung 4, sim, stacks); WINPROB_FAMILY (T178) stacked candidates and the stack failed its playoff slice; the 2019-21 data are a different data-generating process (shortened seasons, bubble, empty arenas, ~3 report snapshots/day before the hourly era, no PDFs before 2019-11-10, 2021-22 the deviant hourly era). The expected outcome is a null.
* **E1 (pts only).** A pre-tip minutes gate routes between A1 (XGBoost) and A0 (production mixture) and beats A0 by the floor in both seasons.
* **E2 (all four stats).** The transformer blended with A0 beats A0 by the floor in both seasons, with 2023 as a clean select season (SEQ has never produced a 2023 out-of-sample forecast).
* **E3 (all four stats).** The same transformer trained also on 2019-20 and 2020-21 (reports missing) beats A0 as a blend AND beats E2 as a blend.
* **E4 (pts).** E1 and the better of E2/E3 together beat each of their parts.
Priors, stated before any arm exists: E1 passes both seasons ~8% (range 3-20%); any E2 cell ~12% (pts the only plausible cell; fg3m blends were -0.003, below the floor, against the weaker old comparator); any E3 cell ~10%, and E3 beating E2 ~5%; E4 ~4%. Reasoning for E1: the bound is the oracle. If the gate were perfect, E1 would take A1's gain on rows >= 5 minutes (-0.0148 x 0.916 = -0.0136) and A0's accuracy under 5 minutes. A pre-tip gate with AUC 0.87 knows only a third of the short rows (P(< 5 min | g < 0.9) = 0.32-0.35), so the recovered share rho must be >= 37% in 2024 (where A1 - A0 is 0.0000) to reach -0.005. Soft weights near 1 for most rows make that unlikely.

**E1 minutes-gated mixture (pts).** Gate score `g` = P(minutes >= 5 | plays) = survival at 5 minutes of the production truncated-normal minutes distribution (`production_minutes_table`: `p_mu`, `p_sigma`, as-of, `use_game_context=False`, the minutes path as it stands; no actual minutes, no tonight's box score, no report). Forecast = integer-support pmf `g * pmf(A1) + (1 - g) * pmf(A0)`, quantiles by the smallest integer k whose cdf >= tau on the 199 grid. No tuned constant: the weight is the probability. A1 = the frozen XGBoost pts arm, the stored refit units (`data/ops/xgb_pts_vs_lt_cache/units/A1/pts`, 18 month blocks, reproduced by XGB_PTS_VS_LT). Descriptive companions, never in the rule: **E1-oracle** (weight = 1[actual minutes >= 5]; shows what the router loses by not knowing minutes) and **E1-hard** (A1 if g >= 0.9, else A0).
**E2 sequence transformer, replicated (all four stats).** The model of docs/SEQ_PROPS.md as specified (2 layers, d=64, 4 heads, pre-norm, dropout 0.15/0.4, 15% player-id dropout, AdamW wd 5e-2, 19 monotone quantiles + mean over the shrunk recency mean, pinball + 0.1 MSE, transformer arm only, seeds 0, 1, 2, Vincentized), on a FRESH export of the current database (`research.features.player_sequences`, 84,170 targets; the 2026-10-08 export is stale, section G2). Epochs 25, patience 4, batch 1024, lr 1e-3 for the cold fit. Arms scored: E2-alone, E2-50/50 (quantile average with A0), E2-learned (softmax gate of `research.stack.router`, 30-day blocks, `min_train_rows` 3000, context columns `log_n_prior`, `starter10`, `n_rep_out`, `has_report`, `team_game_no` (the T065 evaluation's), fit only on rows dated strictly before each block, candidates [A0, SEQ] on the 19-level grid (the 199-grids interpolated at tau 0.05..0.95), run once over 2023 and 2024 together so the 2024 blocks also learn from 2023; rows before the gate's first fit use 0.5/0.5 so every arm has the same rows). ## Rows, supports, metric, inference
Scored rows: the A0 keys (played, `n_prior >= 5`; 27,619 / 27,701 per stat; all are in the fresh SEQ export, G2). E1/E4 and anything compared with them use the A0 ∩ A1 intersection (27,619 / 27,583; A0-only keys 0.426% <= 0.5%, labels equal on shared keys, as XGB_PTS_VS_LT check 5). Every arm, for every stat, goes through `to_integer_support` and `crps_from_quantiles` on the 199 grid (pts, reb, ast, fg3m alike); no arm is scored on a continuous support. Primary metric: paired delta of integer-support CRPS (arm - A0) per row, 95% CI by game-clustered percentile bootstrap (2,000 resamples, seed 0; cluster = `game_id`; `paired_score_delta_ci`), two-sided clustered p (`boot_p_value`). n reported with every number.
**Confirmatory family, per season (BH q = 0.05 within the season, `bh_adjust`): 26 cells** = E1 (1: pts) + E2 {alone, 50/50, learned} x {pts, reb, ast, fg3m} (12) + E3 same (12) + E4 (1). Alone cells are in the family although they are expected to lose (they cost BH little and cannot be dropped after the fact). **Secondary family (BH over 4 stats, per season):** D = E3-50/50 minus E2-50/50 (same rows), floor -0.0025 (half the floor), the "more data helps" claim.
Select 2023, report 2024. Descriptive and outside every family: E1-oracle, E1-hard, E2o, K and S arms standing alone, A0off contrasts, MAE, GRU.

## PASS RULES (frozen text when frozen)
A cell passes a season iff delta <= **-0.005**, CI upper < 0, BH p < 0.05 in that season, AND the guards below hold. A cell is **confirmed** iff it passes 2023 (select) and 2024 (report): the same cell, both seasons, both point estimates negative and at the floor. A blend that passes only one season, or whose two directions disagree, is not confirmed.
* **Guards, both seasons unless noted:** (g1) calibration of the scored forecast: |bias| <= 0.5, 80% continuity-corrected randomized-PIT coverage in [0.75, 0.85], lower-tail guard (coverage within 0.02 of nominal at 0.10, 0.20, 0.80, 0.90, 0.95); (g2) no slice with n >= 300 worse than A0 by more than +0.01: regular season vs postseason (game_id not starting `002`: playoffs and play-in; the T178 stack failed exactly here), starter vs bench, cold start (`n_prior < 20`), first 15 team games, teammate OUT (`n_rep_out >= 1`), realised-minutes buckets (< 5, 5-20, > 20; descriptive stratifier of where a gain sits, never an input); (g3) concentration: no team carries more than 25% of the summed gain, and the delta without the largest team still <= -0.0025; (g4) **thresholds, pts cells only:** log loss of P(pts >= N) at the DraftKings T-60 main lines (the ODDS_HISTORY pairs frames, one x.5 line per player-game) mean(arm - A0) <= +0.002, and at fixed N in {20, 25, 30} none worse than +0.005; (g5) proxy-safe subset (real tip at or after 19:00 ET; SEQ reports are gated on the real-tip T-60 cutoff, A1's frame on a 19:00 proxy): mean delta <= -0.005 for E1/E4; (g6) **shuffled label control:** the S arm's blend delta must be > -0.001 (CI includes 0 or is positive) for the same stat; if the shuffled inputs also "win" the cell is void (it is a baseline-or-blend-weight artefact); (g7) **planted future and same-game** (unit tests, below) pass; (g8) **missingness audit:** NULL/zero share of every SEQ input channel by realised-minutes bucket (< 5, 5-20, > 20) differs by <= 2 pp (columns whose status is constant within player or month exempt, computed by the harness, never by name), as in XGB_PTS_VS_LT check 3; and the **bucket audit of g itself**: g is computed without actual minutes (test: replace every actual minutes value and the final score; g unchanged).
* **Knockout guard (E2 and E3 cells):** a confirmed E2 or E3 cell must survive removal of the report tokens: the same cell of the K arm (blend with A0, report channels zeroed in the SEQ model only) must have delta vs A0 <= -0.0025 in both seasons for that cell (a gain that disappears with the report channels removed is a report gain A0 already has, not a sequence gain). For E3 additionally E3K-50/50 - E2K-50/50 <= -0.0025 in both seasons for the cell claiming "more data". A confirmed cell that fails is FAIL_KNOCKOUT.
* **Era identification (E3 only; protects against the model reading the era, not the basketball):** (P-in, a gate) LightGBM (100 trees, 15 leaves, seed 0, game-level hold-out `sha256(game_id) % 3 == 0`) on the 0/1 "channel exactly zero" indicators of every non-report context channel (report channels are declared and excluded): AUC history-vs-2022 (2019, 2020, pooled), game-clustered 95% interval (B = 200); stated limit = max(placebo AUC over 2022v2023, 2022v2024, 2023v2024, 0.505); flagged when the interval LOWER end exceeds the limit. (P-emb, a verdict guard) after the E3 fit, logistic regression on the 64-d target-token state of held-out rows, history (2019, 2020) vs 2022 and the placebo pairs 2022v2023, 2022v2024, 2023v2024 on the same states: stated limit = AUC(2022v2024) + 0.02 (history is 2-3 seasons from 2022, so a pair at the same gap is the fair placebo; the 3-season 2019 gap makes the guard conservative against E3). E3 with a flagged P-emb is FAIL_ERA whatever its CRPS. E3 with a flagged P-in at the gate is not frozen.
* **Verdicts:** per cell PASS-2023, CONFIRMED, FAIL_KNOCKOUT, FAIL_ERA, VOID_SHUFFLE, or HARM (delta >= +0.005 with CI lower > 0 in either season; any HARM blocks a shadow proposal for that arm). E1 passes iff its single cell is confirmed and g1-g5, g7-g8 hold. E4 is "additive" iff confirmed and E4 - E1 and E4 - (best SEQ 50/50 on the same rows) are both negative at the point estimate (descriptive CIs). A PASS means a **shadow arm** in the live log and a red team, never a promotion (Devin's), never a 2025 touch.

## What each choice protects against
| choice | protects against |
|---|---|
| comparator = the shipped mixture A0, not A0off or the old production | a gain that is the mixture's tail fix in disguise (the SEQ blend's -0.0058 was against production without it) |
| integer-support scoring for every arm and stat | the T114-T118 artefact (92-126% of a "gain"); SEQ's 19 levels are mapped by the same ext_tails + `ceil(q - 0.5)` |
| g from the production minutes path, no actual minutes (test g8) | the oracle leak: routing on realised minutes would show -0.0136 for free; the oracle is reported only to show what the router loses |
| weight = g, no tuned threshold or exponent (hard route descriptive) | tuning the router on the seen T387 slices |
| select 2023 / report 2024, confirmed = both seasons, floor -0.005 + CI + BH over 26 | picking the one cell and season that works; a significant-but-useless delta; a single-season lucky blend (2024 was already seen once) |
| walk-forward blend weights, gate fit only on earlier rows | the learned gate seeing the rows it is scored on (selection inside the evaluation); the 50/50 weight is fixed and untuned |
| `best` for E4 chosen on 2023 pts only, by formula, declared now | choosing the ensemble partner after seeing 2024 |
| fresh export, same window per protocol, walk-forward over both seasons | scoring the stale 2026-10-08 export (usage, zones, pace, drtg changed on 45-98% of rows after the possession rebuild) and pretending it is the old run |
| E3 history built in a separate pass, 2021-22 excluded, report channels zero, `pos_*` complete | a 15-month gap in recency windows; the model reading the era from a NULL pattern (`pos` NULL on 21.5% of history rows would be an era flag) |
| P-in / P-emb with placebo-derived limits | era identification through values or missingness the CRPS alone cannot show (HW3: value AUC is 0.96-0.998 even between adjacent current seasons, so only a placebo-relative limit is meaningful) |
| knockout K arms, shuffled S arms | a gain that is the report channels, the blend weight, or any structure that survives with the inputs scrambled |
| g1-g5 slices, thresholds 20/25/30, DK lines, team share, proxy-safe | the postseason reversal, one-team concentration, thin-upper-tail CRPS gains, and early-tip proxy exposure |
| E1-oracle descriptive | reading the router's shortfall as a model failure when the information was never available at tip |
