2. 3. Comparator **A0** = production + the stored lower-tail mixture (`reports/lower_tail/`, integer support; pts 3.140236 / 3.176840, reproduced to 1e-6). ## Construction (fixed here)
**g'.** Rows: the RECENT_ROLE Cell-P frame (rostered, not OUT on the real-tip T-60 report, `n_played_prior >= 5`; `tip_source="real"` through `pplay_context_eval.prepare`), PLAYED rows only; label `min_real >= 5`; features `recent_role_eval.arm_columns()["R"]`; classifier `_params(cfg, "binary")` (production binary LightGBM, seed 0, deterministic) with `recent_role_eval.walk` (month blocks 2023-10 .. 2025-06, 18; training rows are every earlier played row since 2022, so the warm-up is the 2022 season). Training on played rows makes g' the conditional the mixture weight needs, P(minutes >= 5 | plays); it is not P(plays) (the A0 rows are played rows, so an unconditional probability would underweight every row). No tuning of any kind.
**g_eff.** g' where the A0 row has a g' and `game_id[:3] == "002"`; otherwise 0. 55,301 of 55,320 A0 rows have g'; the 19 without (7 / 12, all regular season, mean 5.5 minutes) are rows the T-60 report lists OUT who played; they take A0 (stated, pre-tip known). Postseason (004) and play-in (005) rows take A0.
**TAU = 0.90.** A forecast is used only where g_eff >= 0.90, i.e. where P(minutes < 5 | plays) <= 10%. Derivation, fixed before any arm is scored: from T442's stored slices the blend gains about -0.018 per row on rows with >= 5 minutes and loses about +0.056 per row under 5, so break-even is P(< 5) of about 0.25 (g' = 0.75). But the guard "minutes < 5 slice not worse than +0.01" would then fail by construction unless at least about 82% of the near-DNP rows are routed away, and the guard is part of this rule; the threshold consistent with the guard is the next round value, P(< 5) <= 10% (about the 8.6% base rate of such rows). **Disclosure:** I first looked at 0.75 in a probe (it routed 12% of rows and caught 70% of near-DNP rows) before writing 0.90; no CRPS of any arm and no other threshold were looked at. At 0.90 the gate measurement (below) routes 23.7% / 24.7% of rows to A0 (of them 6.5% / 7.0% postseason rows) and catches 87.7% / 88.3% of the rows under 5 minutes.
**Arms.** `router_grid` is `near_miss_bundle_eval.router_grid` (pmf mixture on the integer grid; the 118 pts rows with no A1 row take weight 0). The learned blend is `near_miss_bundle_eval.learned_blend` (ENSEMBLE E2's: 30-day blocks, softmax gate, >= 3000 earlier rows, context `log1p(n_prior), starter10, n_rep_out, has_report, team_game_no`; rows before the first fit weigh 0.5 / 0.5; first stage for E2' is the continuous mixture grid so it reproduces T442 to the last digit; first stage for E4' is E1''s integer grid). The blend is fitted on ALL rows (as T442) and routing only chooses which forecast a row is scored with, so E2' is exactly "T442's E2 learned, routed", attributable and reproducible.

## Primary metric, floor, inference, family
Integer-support CRPS (199-grid, `crps_from_quantiles`), paired per row, CELL minus A0, 95% percentile bootstrap clustered by `game_id` (2000 draws, seed 0), two-sided clustered-bootstrap p. **Floor -0.005.** Family m = 6 (E1' pts, E2' pts, E2' reb, E2' ast, E2' fg3m, E4' pts), BH q = 0.05, separately for 2023 and 2024 (the cells share rows and members, so they are positively dependent, the case BH covers). Both seasons must satisfy point <= -0.005, CI upper < 0 and BH p < 0.05.

3. Placebos, in EACH season, arm minus X <= -0.001 with CI upper < 0, for every X: **PL_G** (the same cell with the gate fitted with the five recent-role columns replaced by one strictly earlier row of the same player-season, RECENT_ROLE's placebo), **PL_A1** (E1', E4': A1's grid from one strictly earlier row of the same player, seed 1), **PL_SEQ** (E2', E4': SEQ's grid likewise, seed 2), and **CONST** (the same cell with a constant gate: per block the base rate of the label over earlier rows, same hard route; this is the gate with no information, so the cell must beat "use the member on every regular-season row").
4. Shuffled-label checks that retrain or refit and can fail (both seasons): **SHUF-G** g' trained on ONE permutation of its training labels per block (`default_rng([0, block])`), cell minus the CONST cell, FAILS if point <= -0.001 with CI upper < 0; **SHUF-C** labels drawn from A0's own predictive distribution (A0 is the truth), the blend gate refit on them, every stored member and g_eff as is, cell minus A0 on those labels must stay above -0.0025 (half the floor).
