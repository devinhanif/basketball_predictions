## Hypothesis
Production gives every teammate the same team totals of the rotation players OUT tonight (`vac_min`, `vac_{stat}`); it does not know WHO absorbs them. H1: per-player columns built from past team games in which tonight's OUT teammate j missed the game entirely while player i played (i's minutes, FGA and 3PA, rebound and assist rates per 36, per-game production, with and without j, shrunk by the number of games without j) lower integer CRPS of i's props beyond the team totals, mainly through minutes. H2 (minutes route): the same columns inside the minutes model do the work, and feed the props. Null: no change.

## Features (as-of; `nba/props/wowy.py`, unit-tested in `tests/props/test_wowy.py`)
For player i of team T in target game g (`kg` = T's global game order across seasons, by date then game_id):
* **OUT set O(g, T):** the production rule, exactly: `player_availability` rows of the official report usable at real tip - 60 min (`flagged_from_availability`, `tip_source="real"`), restricted to rotation players (as-of `min40 >= 12` and at least 5 prior played games, `out_rotation_players`, parity-tested against `vacated_features`).
* **Stint of j with T:** the run of j's appearances (minutes > 0) for T that ends at his last appearance strictly before g's date; if his last appearance before g was for another team he has no stint (traded players drop out); h counts as a teammate game only from the first game of that stint. Reason: the box lists only dressed players (Embiid 2023: 50 box rows in 89 PHI games), so "absent" cannot be read from a missing row; a stint start makes absence-before-arrival impossible.
* **Window and pairs:** h = T's previous 100 games before g (across the season boundary). Only games where i played enter either side. WITH = j played in h, WITHOUT = j did not. `delta_q = n_wo / (n_wo + 6) x (mean_q[WITHOUT] - mean_q[WITH])`, zero when either side is empty; per-36 rates use summed stats over summed minutes; the columns sum over j in O without i.
* **Columns (11):** per-game deltas `wo_d_min`, `wo_d_pts`, `wo_d_reb`, `wo_d_ast`, `wo_d_fg3m`; per-36 deltas `wo_r_fga`, `wo_r_fg3a`, `wo_r_reb`, `wo_r_ast`; confidence `wo_conf` (sum of the shrink weights); `wo_n` (sum of games without j). Each stat head gets five (`wo_d_min`, `wo_d_<stat>`, the stat's rate column, `wo_conf`, `wo_n`; pts: `wo_r_fga`, fg3m: `wo_r_fg3a`); the minutes model gets `wo_d_min`, `wo_conf`, `wo_n`.
* **Assists:** the player's own box assists in games he played. `possessions.assister_id` is NOT used (NULL for accented passers, defect D15, open; 91.2% coverage). Stints and possessions are not used at all (box is exact for "j missed the game"; a stint-based "j on the bench" variant is a different question: the follow-up candidate, WOWY_STINT).
* **Missingness:** report and nobody rotation-OUT -> explicit 0; OUT but no pair information -> 0 with `wo_conf = 0`; no usable report -> NULL (never "nobody out"); same rule as production's `vac_*` (`attach_wowy`). Firing is by pair history, tested below.
* Constants (final, no tuning): window 100 games, shrink K = 6 games, rotation 12 min, 5 prior games. Not tuned: BEST_PRACTICES says features, not tuning.

## Metric, inference, pass rule
* Integer-support CRPS per stat on the A0 row set (played, `n_prior >= 5`); paired; 2000-draw percentile bootstrap clustered by `game_id`, seed 0; date clustering reported (worst design effect used for sizing).
* **Pass (per cell, both seasons):** primary-slice difference <= -0.005, CI upper < 0, BH-adjusted p <= 0.05 over m = 2 (pts x {W_HEADS vs A0_refit, W_MIN vs M_BASE}); all guards. reb, ast, fg3m: reported with CIs and labelled "descriptive: floor unreachable at the estimated effect"; they cannot pass and cannot veto. If Devin wants BH over all 8 cells instead, points power falls (about 0.15 per season at the best estimate).
* Guards: (G1) all rows, difference <= +0.001 (its half-width is 0.0040, so it guards against gross harm only, not against harm below about 0.004); (G2) PLACEBO: W minus PLACEBO <= -0.003 on the primary slice each season; (G3) NOISE: W minus NOISE <= max(0.003, 2 sd of the permutation null); (G4) A0_refit reproduction (above), planted-future and missingness tests (below); (G5) coverage at tau 0.10 / 0.20 / 0.80 / 0.90 (randomised PIT on the integer grid, fixed row order) within 0.01 of A0; (G6) slices with n >= 300 not worse by more than +0.01: bench and starter, n_out_rot = 1 and >= 2, a star out (an OUT teammate with `min40 >= 30`), first 15 team games, playoffs, rows with `wo_conf = 0`.
* The minutes route also reports minutes CRPS (continuous, minutes) for M_BASE and W_MIN, descriptive, no floor.

## Why these choices (what each protects against)
* Game-level absence from the box, not stints/possessions: exactly the condition tonight (j is not in the game), no name-matching defect, no dependence on the rebuilt lineups; a stint version would measure j sitting while the other four starters are on the floor, a different condition.
* VAC24 primary slice and a family of two: a slice that holds 97% of games protects nothing; an 8-cell family with six cells that cannot reach the floor would spend the multiplicity budget on them. Both choices are made from the gate, not from an outcome.
* Floor -0.005, integer grid, clustering by game: house rules (the playbook's CRPS-not-line caveat stands).
* PLACEBO changes only WHO is out: if the real columns beat it the identity matters (the claim); if not, the gain is the machinery or the capacity. NOISE tests capacity with real labels (MINUTES_V2's noise made pts worse by 0.003, so the guard is also against a harm).
* A0_refit: protects against a comparator that differs from the candidate in data version. M_BASE: protects against crediting WOWY for what a second minutes model already gives (T166-T167).
* Shrinkage by games without j (K = 6): a pair seen in 2 games must not move a forecast; the columns carry `wo_conf`, so the model can learn how much to trust them.
