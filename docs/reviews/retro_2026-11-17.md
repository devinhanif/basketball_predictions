About 12 hours (first commit 18:56 CST on 11-16), two briefs (SUPER PROMPT v3, then the Jarvis follow-up), one main

- Recommended in the follow-up: land the switch and its parity proof first, then the look, then the betting screens.
  Done in that order, so every later merge could be checked with the switch off.

## What held up

- Merging a lane only after its own checks and then running the gate on the merged tree. Two lanes that were each green
  alone were never assumed green together.
- Flag parity as a build step. It caught nothing tonight, which is the point: no lane could leak betting code into the
  switch-off bundle without the check failing.
- Looking at screenshots as well as checks. The checks passed while a notice covered the Compare board, while unit
  labels broke mid-word, and while a phone's first screen was two lines of the same sentence.
- A second and third pass by a lane with a different brief (a friend on a phone; the two main pages top to bottom; a game
  night) found things the building lanes did not: a 38,000 px Analyst page, source file paths in Simple mode, 404
  requests for unfinished games.

## What went wrong

- Clock times were guessed in early worklog rows and status messages (up to 20 minutes off). Fixed by running `date`
  before writing any time.
- The route walker picked its devtools port from its seed, so two walkers drove each other's browser. This cost about an
  hour of "flaky" failures before the cause was found.
- A lane killed a headless Chrome that was not its own. No work was lost.
- A walk ran while a merge changed the same worktree; the dev server reloaded mid-step and the walker reported two
  violations that were not real.
- A wait loop matched its own shell with `pgrep -f` and never ended.

## Rules to add, change or delete

- Add (BEST_PRACTICES, incident above): a browser check takes its ports from the system, never from a seed or a fixed
  number shared between runs.
- Add: a process is killed by a port or PID the killer started, never by name or by a profile path that looks familiar.
- Add: no edit, merge or checkout in a worktree while a browser check is running from it.
- Add: a time in a log comes from `date`.
- Keep: a display or wording change that a test pins is changed together with the test, in one commit, and said in the
  hand-back.
- Propose for deletion: none tonight.
